Add one SDK. Get APM, RUM, logs and alerts that know your code.

Install, set a DSN, deploy. Your service shows up in the dashboard with the first request, even at zero traffic.

go get github.com/makifbaysal/tasktrooper-telemetry/sdks/go

// 2. initialise
shutdown, err := trooper.Start(ctx, trooper.Config{
    DSN:     os.Getenv("TROOPER_DSN"),
    Service: "orders-api",
})
defer shutdown(ctx)
3. Deploy. Traces, metrics and logs flow over OTLP; nothing else to configure.
